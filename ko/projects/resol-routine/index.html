01 / 프로젝트 소개

Resol Routine

Resol Routine은 한국 중·고등학생을 위한 영어 듣기·읽기 학습 앱입니다. 백엔드는 학습 이벤트와 단어 복습, 학부모 리포트를 연결합니다.

02 / 어떤 문제였나

어떤 문제였나

완료한 퀴즈는 답안을 복원하고 일관된 리포트를 만들 수 있을 만큼 충분한 기록을 남겨야 합니다. 재전송은 올바른 계정 안에서 처리돼야 하며, 학부모 리포트는 로그인 여부만으로 접근을 허용해서는 안 됩니다.

03 / 어떻게 결정했나

어떻게 결정했나

버전별 학습 이벤트를 검증하고 퀴즈의 전체 답안을 보존합니다. 동기화와 재전송 처리를 계정별로 구분하며, 학부모 리포트에는 활성 자녀 연결과 이용 권한을 함께 요구합니다.

04 / 구현 방식

구현 방식

단어 학습 이벤트는 전체 답안, 문항 식별자의 중복 여부, 오답 기록과 제출된 퀴즈의 일치 여부를 검사합니다. 동기화는 퀴즈 답안과 개인 단어 변경 사항을 복원합니다. 리포트 접근 시에는 인증, 자녀 관계, 이용 권한을 각각 확인합니다.

05 / 선택에 따른 부담

선택에 따른 부담

이벤트 검증이 엄격할수록 클라이언트는 완전하고 일관된 기록을 보내야 합니다. 재시도 안전성은 동기화의 일관성을 위한 장치이며, 클라이언트가 보낸 학습 결과 자체의 진실성을 보장하지는 않습니다.

06 / 확인한 결과

확인한 결과

기록된 로컬 HTTP 통합 검사에서는 답안 복원, 리포트 집계, 계정 간 데이터 분리와 인증된 계정 삭제를 확인했습니다. 저장소에는 중복 재전송, 계정 범위, 학부모 리포트 권한을 확인하는 테스트가 있습니다.
