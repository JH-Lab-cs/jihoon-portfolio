01 / 프로젝트 소개

Placia

Placia는 사진과 장소를 중심으로 여행의 기억을 정리하는 온디바이스 여행 사진 아틀라스입니다. 이 사례는 계정 생성, 첫 기기 승인, 세션 발급을 담당하는 내부 백엔드를 다룹니다.

02 / 어떤 문제였나

어떤 문제였나

서로 다른 계정이 같은 기기 키를 동시에 등록하려는 요청이 충돌할 수 있었습니다. 첫 로그인 도중 중단되면 인증 권한만 소비되고 사용할 계정과 세션은 남지 않을 수도 있었습니다. 일부만 완료된 상태가 다음 요청에서 정상으로 처리되지 않도록 해야 했습니다.

03 / 어떻게 결정했나

어떻게 결정했나

첫 로그인을 하나의 상태 변경으로 처리했습니다. 계정 생성, 첫 기기 승인, 세션 발급, 암호화된 재시도 응답을 하나의 PostgreSQL 트랜잭션으로 묶었습니다.

04 / 구현 방식

구현 방식

기기와 키를 일정한 순서로 잠그고, 완성되지 않은 트랜잭션은 지연 검사하는 DB 제약으로 거부합니다. 동일한 요청을 다시 보내면 기존 세션을 반환해 별개의 로그인 결과를 만들지 않습니다. 인증 만료 중 정리 작업이 실행되는 경우도 회귀 테스트에 포함했습니다.

05 / 선택에 따른 부담

선택에 따른 부담

일관성을 확보하는 만큼 잠금, DB 제약, 암호화 키 관리가 복잡해집니다. 통합 테스트는 이 장치들이 실제로 함께 작동하는지까지 확인해야 합니다.

06 / 확인한 결과

확인한 결과

해당 구현 체크포인트에서 단위·HTTP 테스트 201건과 PostgreSQL 통합 테스트 70건, 타입 검사·린트·빌드·CI가 통과했습니다. 동시 키 등록, 미완료 트랜잭션, 만료 중 정리 작업이 회귀 테스트에 포함됩니다.

원자적인 기기 등록

계정 생성, 기기 승인, 세션 발급이 하나의 트랜잭션 안에서 완료됩니다.

07 / 현재 구현 범위

현재 구현 범위

내부 인증 서비스에 관한 사례입니다. 확인한 체크포인트에서는 실행 진입점의 공개 인증 경로가 활성화되지 않았습니다. 출시된 연결 로그인 경험을 검증한 결과는 아닙니다.
